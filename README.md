# Sprinters Book - Static Website

A clean, fully-functional static website built with pure HTML, CSS, and vanilla JavaScript. No dependencies required.

## 📦 Project Structure

```
.
├── index.html              # Homepage
├── about.html              # About page
├── contact.html            # Contact page
├── assets/
│   ├── css/

│   ├── js/
│   │   └── script.js       # Interactive features
│   └── images/             # Images and logos
└── README.md               # This file
```

## 🚀 Quick Start

### View Locally

```bash
# Navigate to project directory
cd sprinters

# Start a simple HTTP server
python -m http.server 8000

# Open in browser: http://localhost:8000
```

### Deploy

**Option 1: GitHub Pages**
1. Push to GitHub repository
2. Enable Pages in repository settings
3. Site available at: `yourusername.github.io/sprinters`

**Option 2: Netlify**
1. Drag and drop folder to Netlify
2. Deploy instantly
3. Get auto SSL certificate

**Option 3: Vercel**
1. Connect GitHub repository
2. Auto-deploys on every push

**Option 4: Traditional Hosting**
1. Compress folder as ZIP
2. Upload via FTP
3. Extract in public_html directory

## 🎨 Customization

### Change Colors
Edit `assets/css/style.css`:
```css
:root {
    --primary-color: #1bb0ce;
    --secondary-color: #1a2d4d;
}
```

### Update Content
Edit HTML files directly with any text editor.

### Change Contact Links
Update WhatsApp and Telegram URLs in HTML files:
```html
<!-- Change these URLs as needed -->
<a href="http://wa.link/yourlink">WhatsApp</a>
<a href="https://t.me/yourlink">Telegram</a>
```
